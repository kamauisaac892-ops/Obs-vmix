# Our Production Studio — Web Console v0.1

Independent browser-based live production console.

Current milestone:
- Program / Preview workflow
- Scene switching with TAKE / FADE / SWAP
- Camera 1 / Camera 2 browser capture
- Screen sharing
- Graphics placeholders
- Audio mixer UI
- Browser recording to WebM where supported
- Responsive desktop/tablet/mobile layout

Camera and microphone access require HTTPS (or localhost) and explicit browser permission.
